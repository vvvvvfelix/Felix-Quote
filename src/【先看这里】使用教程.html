功能速查

功能能做什么
产品库管理设备参数：规格、材质、净重毛重、证书、FOB 价格
报价单制作选客户与产品，自动算总价，一键导出 PDF 发给客户
资料库Excel / PDF / 截图 / 照片丢进来，自动识别成产品数据
客户管理维护海外客户的地址、付款方式、贸易条款
报价模板按需修改报价单版式（内置 3 套可编辑模板）
供应商管理自有产线与外协厂商，按品类区分参数体系

遇到问题怎么办

第一步：双击「检查依赖.bat」
它会直接告诉你问题出在哪、该怎么处理。
看到什么提示原因与解决办法
图片识别不可用
（Windows 7 / Vista）		 原因：系统版本过低，AI 推理引擎不支持。
影响：仅"上传截图/照片"这一个功能。
可用：产品库、客户、报价单、PDF 导出全部正常。
替代方案：用 Excel / PDF 文件导入，同样能自动识别产品参数。
缺少 Visual C++ 运行库 原因：系统未装微软 VC++ 2015-2022 运行库。
解决：安装官方运行库后重启电脑
https://aka.ms/vs/17/release/vc_redist.x64.exe
内存不足 原因：可用内存低于 700MB，模型加载不下。
解决：关闭浏览器多开、Office、CAD 等程序后重试。
建议：本机内存 4GB 以上。
模型文件缺失 原因：模型被杀毒软件删除，或压缩包解压不完整。
解决：重新完整解压，并检查杀毒软件隔离区。
双击没反应 / 闪退 原因：解压不完整、权限不足，或路径含中文空格。
解决：① 确认"完整解压"而非直接双击压缩包内文件
　　　　　② 右键启动.bat → 以管理员身份运行
　　　　　③ 解压到 D:\VG 这类不含中文空格的路径
端口被占用 解决：双击【启动-指定端口.bat】换个端口； 或先双击【停止服务.bat】结束残留进程。

安全与隐私

  • 数据只存在你自己的电脑上，不上传任何服务器
  • 全程离线，不需要网络连接
  • 零 Token 消耗，所有计算都在本机完成
  • 数据位置：data\wv.db（数据库）、 app\static\uploads\（上传的原始文件）
  • 换电脑：复制整个文件夹到新机器，双击启动即可
  • 杀毒软件偶尔误报绿色打包程序，添加到信任列表即可
