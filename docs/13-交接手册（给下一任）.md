## 一、这是什么（30 秒定位）

- **产品**：「Felix 企业管理平台」——由「Felix 报价系统 v1.3.0」演进来的集团型多组织 ERP+OA 平台。
- **形态**：本地便携版，单进程 **FastAPI + SQLite(WAL)**，双击即启动；运行时自带 Python 3.13。
- **前端**：**原生 JS 单页**，无构建链（改完即生效）。Vue 3 全局构建，`static/js/pages/*.js` 每页一个组件，`static/app.css` 放样式，设计令牌在 `:root`。
- **代码位置**：`E:/workbuddy/felix-quote/src/app/`（`core/` 基础设施、`modules/` 领域模块、`main.py` 装配、`seed.py` 演示数据）。

## 二、铁律（违反即烂）

1. **迁移只增不删**：`core/schema.py` 里 `_vNNN(db)` 函数只追加，禁止改已发布迁移（见 10 §2.2）。
2. **模块禁止互 import**：跨域走 `core/services.py` 或 HTTP 调自身 API（见 00 §二）。
3. **前端类型中文不硬编码**：枚举值在模块顶部 dict 定义，前端从 `/api/.../types` 取（如组织类型）。
4. **品牌/后端红线**：`index.html` 标题、`login-hero` 文案、后端 `.py` 非经授权**不得改**（品牌归 M006/M113 线，方言中立归 M108）。
5. **PC 优先 + 响应式 Web**：桌面布局零改动是回归红线；手机态只在 `@media(max-width:760px)` 内新增规则。

## 七、本项目专属坑（接手必看，避免重复劳动）

### 协作 / 工具类
- **P-A1 架构师 agent 跨会话丢状态、迟到文档覆盖主理人规范**：长任务 agent 在上下文压缩后会"迟到"返回，且可能覆盖你已写好的文档、约定还不同（断点/类名/z-index 都对不上）。**以代码为最终事实**，文档按代码重写，不轻信迟到文档。
- **P-A2 已完成状态要落盘**：上下文压缩会丢掉前序已完成细节（如"M001 后端早已完成"）。关键进度写进 `docs/02-PROGRESS.md`，别只存在于对话内存，否则会重复确认。
- **P-A3 子代理 429 额度耗尽**：密集多轮把 API 额度打光，worker 跑一半失败。额度恢复后**用 SendMessage 续活着的 worker**，别重新 spawn 从零。
- **P-A4 Glob 在 Windows 路径偶发返回空**：改用 `Bash ls` 更稳。
- **P-A5 本工作区没有 git 仓库**（`git status` → not a repository）：无法用 `git diff` 证"后端零改动"，只能靠变更清单 + 包完整性判定。**交付前先确认有无 VCS**；没有就明确告知用户，别假设有。
- **P-A6 跨会话时钟不一致**：`docs/02-PROGRESS.md` 出现 2026-11-02，而沙箱 `date` 是 2026-11-01。日志以"本环境 date"为准，跨会话引用日期要谨慎。
- **P-A7/P-A8 品牌与后端红线**：UI 改造严禁改 `index.html` 标题与 `login-hero`；任何"顺手优化"都别碰 `src/app/**/*.py`。

### UI / 响应式类（对应 `docs/10` §8.1–8.7）
- **P-UI1**（§8.1）`app.css` 中 `.grid2/.grid3/.grid4` 被重复定义 3 次（末版 gap:11px 为准）。新增响应式类**只追加不改**，避免级联歧义。
- **P-UI2**（§8.2）`.sidebar` 桌面是 `position:sticky`；手机变抽屉必须在**既有 sticky 规则之后**再写 `position:fixed`，否则被覆盖不生效（媒体顺序敏感）。
- **P-UI3**（§8.3）iOS 视口用 `top:0;bottom:0` 固定定位，规避 `100vh` 工具栏误差。
- **P-UI4**（§8.4）`data-label` 机械活易漏：每个要转卡片的 `<td>` 都要加；漏一个卡片就缺标签。带缩进 span 的首列也要加。
- **P-UI5**（§8.5）抽屉/弹窗 z-index 必须 抽屉<弹窗（80<100），否则弹窗被盖。
- **P-UI6**（§8.6）断点口径全栈统一为 **≤760px**；架构师曾提 767，实现用 760，扩展页不要混用，否则文档/代码对不上。
- **P-UI7**（§8.7）PWA `manifest.icons:[]` 空，严格「添加到主屏」需补 192/512 png；SW 不缓存，运行无影响。
- **P-UI8**（本轮 org/structure 实践）表格转卡片只作用于带 `.tbl.responsive` 的表；未改造表靠 `.tbl-wrap` 横向滚动兜底，不要以为所有表都转了。
