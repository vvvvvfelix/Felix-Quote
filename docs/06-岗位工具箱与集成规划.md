# 岗位工具箱与系统集成规划

> 目标：把"每个岗位在生产过程中会用到的外部软件/系统"结构化沉淀，作为集成规划的单一事实来源。
> 简版映射已内置在 `modules/toolbox.py`（前端「岗位工具箱」只读页实时读取）。
> 本文件是**完整规划**，含对接方案与路线图。

| 厂长 / 生产经理 | MES、CAD/SolidWorks | 生产看板（过渡）、物料需求 | 规划中 / 可互通 |

集成状态三档：
- **已内置**：本系统已实现该功能
- **可互通**：通过导入/导出或对接与对方系统交换数据（不强制深度对接）
- **规划中**：已列入路线图，待实现

## 二、重点集成方案

### 2.1 财务 — 金蝶 / 用友（M070 应付、M072 总账 阶段对接）
- **凭证导出**：本系统应收/应付/费用单 → 生成金蝶/用友标准凭证导入模板（Excel/CSV），财务二次导入。
- **科目映射**：在「财务设置」维护"本系统单据类型 → 对方科目"映射表，导出时自动带科目。
- **不实时直连**：避免强耦合与版本风险；以"导出导入"为第一阶段，API 直连放 M106 之后评估。

### 2.2 财务 — 电子税务局 / 税务 UKey（M071 费用报销 阶段）
- **发票抬头/税号复用**：客户/供应商的税号已进主数据，开票时自动带出。
- **全电发票查验**：规划中，通过税务局开放接口做发票真伪/查重（需企业资质，M106 后评估）。
- **发票打印**：本系统已支持 **A4 单张 / A4 双联（上下两张 A5）** 排版，满足"一张 A4 打两行 A5 票"的普遍要求。

### 2.3 研发 / 技术 — CAD / SolidWorks / AutoCAD / EDA（M080 研发项目、M081 图纸版本）
- **图纸归档**：CAD 图纸作为产品资料导入「资料库」，带版本与受控发布（M081）。
- **BOM 联动**：图纸明细 → 产品主数据 → BOM（M060），减少重复录入。
- **水印**：对外图纸自动加水印（含使用范围与有效期），降低外泄风险。

### 2.4 行政 / 人事 — 携程商旅 / 滴滴企业版（M011 假勤、M021 办公用品 阶段）
- **行程单**：出差行程与交通明细在本系统录入，生成差旅报销依据。
- **水单报销**：微信/支付宝付款水单截图导入 → 自动排版到 A4 → **可选脱敏** → 直接打印提交财务。
  无票单据不再手工贴票，显著降低行政/财务工作量。
- **对接方向**：规划中与商旅平台做订单级对接（自动拉取行程与发票），优先级低于核心单据。

### 2.5 销售 — WhatsApp / 企业微信（M034 通知中心 阶段）
- **消息对接**：规划中，先做"导出跟进表 + 手动发送"，M034 后评估 API 直连。
- **邮件**：已内置 SMTP 发报价单与邮件留痕。

### 2.6 物流 / 关务 — 单一窗口 / 船公司（M064 之后）
- **报关要素复用**：产品主数据的 HS 编码、品名、规格直接复用到报关单草稿。
- **运单导出**：出货单/箱单发票导出为船公司/货代平台可导入格式。

### 2.7 通用 — Office / WPS
- 资料、报表、说明书模板与 Office/WPS 互通：导入解析（已有 docx/xlsx 解析）、导出（reportlab/openpyxl 生成）。
- 制度/通知/合同模板统一在「资料库/合同档案」归档。

## 三、对接原则（避免烂尾）

1. **先导出导入，后 API 直连**：降低耦合与版本风险，第一阶段全部走文件交换。
2. **映射表外置**：对方科目/字段映射做成可配置，不因对方升级而改代码。
3. **不重复录入**：凡是主数据已有的（税号、HS 编码、产品参数），下游单据自动带出。
4. **敏感字段单权限**：财务/薪资/成本类字段独立权限点，与功能权限解耦。
5. **脱敏可关**：涉及打印/导出的脱敏（水单、金额）默认可选，且能一键关闭，满足不同客户合规要求。
