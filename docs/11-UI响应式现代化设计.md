## 2. 断点与层级

**三档断点**
- ≥ 1100px：桌面全功能（216px 侧栏、双栏 1.55fr/1fr），现状不变。
- 900–1100px：复用既有 `@media(900/1000/1180)`（侧栏 64px 图标、`.split`/`.grid2` 单列）。
- **≤ 760px**：手机抽屉态（本次新增）。

**z-index 约定**（手机态，仅 `@media(max-width:760px)` 内生效）
| 元素 | z | 说明 |
|------|---|------|
| `.toast-root` | 200 | 既有，最上 |
| `.mask`（弹窗） | 100 | 既有；弹窗永远盖在抽屉之上 |
| `.sidebar`（抽屉态） | 80 | 新增 `--drawer-z` |
| `.scrim`（遮罩） | 70 | 新增 `--scrim-z` |
| `.topbar` | 20 | 既有（桌面） |

→ 抽屉(80) < 弹窗(100) < toast(200)：无层级冲突。
